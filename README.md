# Free Payment Gateway — Demo

## Run
1. Install Node.js 18+.
2. Open this folder in Terminal.
3. Run: `npm install`
4. Run: `npm start`
5. Open: `http://localhost:3000`

Customer page: `/`
Admin panel: `/admin.html`

## Important
This is a demo/test gateway. It does NOT move real money and does not connect to bKash/Nagad.
For production, add authentication, HTTPS, input validation, rate limiting, secure secrets, audit logs and an official payment-provider API/webhook.
